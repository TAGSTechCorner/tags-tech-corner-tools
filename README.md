# 🐷 TAGS Tech Corner Wealth/Income Tracker

A visual wealth-building dashboard designed for side hustlers, content creators, freelancers, and anyone working toward financial goals.

Instead of using a traditional spreadsheet, TAGS Wealth Tracker helps you visualize your progress with interactive piggy banks, goal tracking, forecasts, and motivational milestones.

---

## Features

✅ Annual Wealth Tracker

✅ 12 Monthly Piggy Banks

✅ Goal Progress Tracking

✅ Income Source Tracking

✅ Achievement Milestones

✅ Forecast Projections

✅ Mobile Friendly

✅ Kiosk Mode for Tablets and Desk Displays

✅ Multiple Color Themes
